# 2026-05-31 对话页内部 Thread ID 暴露与用户激励闭环缺失问题记录

## 事实时间线

- 对话页宠物形象区右上角显示 `pet_mochi_main`，这是系统内部单宠物主群聊 thread id。
- 用户指出“页面是什么东西”，该文案对真实用户没有意义，不应出现在产品界面中。
- 用户同时指出项目本来要做用户激励：每天完成任务得积分、排行榜，但当前应用窗口没有把照护任务、积分和排行串成闭环。
- 用户进一步纠正：用户激励、每日任务和排名不应该全部堆在“我的”页面里；“我的”应该只是入口，点击进入独立激励页后，日常任务和排名还应该继续可点击进入详情页。
- 用户再次纠正：不能把“我的”页改成入口集合，也不能把外观装扮作为和用户激励并列的新入口；服饰里写“奖励获得”的项目，必须在用户激励中看到对应奖励来源和解锁进度。

## 证据

- 截图中对话页顶部标题为“旺财家庭群”，右上角状态胶囊直接显示 `pet_mochi_main`。
- 代码位置：`ai-pet/src/App.tsx` 的 `ChatHome` 中，`online-pill` 直接渲染 `threadId`。
- 知识库已有依据：
  - `modules/function-scope-2026-05-30.md` 中“社区、挑战与分享”包含挑战、排行榜和任务完成。
  - `modules/research-grounded-function-map-2026-05-30.md` 中明确轻量挑战、排行榜或成就卡来自 PawSpace、PetMeet、Adopt Me、Neopets 等产品模式。
  - 但 `modules/INDEX.md` 把社区/挑战模块标为 P2，导致“每日任务 -> 积分 -> 排行榜”没有进入当前 Demo 主闭环。

## 根因

- 对话页把技术身份标识当成连接状态展示，违反“用户界面展示产品语言，不展示内部实现细节”的原则。
- 知识库把“社区/挑战/排行榜”整体归为 P2，没有区分“完整社区”与“任务激励闭环”。
- 照护任务模块只生成任务，没有定义完成任务后的积分、连续天数、成就和排行榜反馈，导致用户动机闭环断开。
- 知识库此前没有独立的用户激励模块 spec，只在修复记录和泛模块描述中写散点结论，导致实现时把“我的页只放用户激励入口”误解成“我的页只剩入口集合”。

## 正确架构判断

- 完整开放社区、UGC 审核、真实比赛运营可以是 P2。
- 但每日任务积分和排行榜不是独立社区功能，而是照护任务模块的反馈层，应作为当前 Demo P0/P1 能力。
- 当前展示阶段应做最小可运行闭环：“我的”页保持宠物档案、知识库和装扮功能，只增加“用户激励”入口；点击进入独立用户激励页；用户可继续进入“每日任务”详情页完成任务并获得积分，也可进入“排行榜”详情页查看和点击排名，并进入“奖励/可解锁服饰”页查看奖励来源和进度；桌宠后续可用气泡反馈挑战进度。
- 装扮页只消费奖励解锁状态，不能负责解释奖励体系；任何“奖励获得”的服饰或配饰必须能在用户激励奖励页找到来源。

## 修复计划

1. 对话页状态胶囊改成“主群聊在线/陪伴在线”等用户文案，不显示内部 thread id。
2. 在领域/UI 层补任务积分模型：不同优先级任务给不同积分，完成后更新今日积分、完成数和连续天数。
3. 先新增并同步用户激励模块 spec，把“我的”页、用户激励页、每日任务、排行榜、奖励/可解锁服饰和装扮页的边界写成权威知识库，不再只写在修复记录。
4. “我的”页保留原有宠物档案、知识库和装扮功能，只增加“用户激励”入口。
5. “用户激励”独立页展示今日积分、本周积分、连续天数、任务完成数、排名摘要和奖励进度，并提供“每日任务”“排行榜”“奖励/可解锁服饰”三个可点击入口。
6. “每日任务”详情页展示所有任务的完成/未完成状态、任务原因、时间窗口和积分，任务可点击完成。
7. “排行榜”详情页展示完整排名列表，排名项可点击查看详情。
8. “奖励/可解锁服饰”详情页展示装扮页奖励服饰/配饰的解锁来源、条件和当前进度。
9. 更新知识库，把“任务积分与排行榜”从泛社区 P2 中拆出来，列入当前 Demo 用户激励闭环。
10. 用类型检查和 Playwright 截图验证对话页、“我的”页、用户激励页、任务页、排行榜页和奖励页。

## 修复结果

- 对话页宠物形象区不再显示内部 `pet_mochi_main`，改为用户可理解的“主群聊在线”。
- 已补齐知识库整体框架：新增用户激励模块 spec，并同步产品规格、产品逻辑框架、当前系统架构、技术架构、模块索引、功能范围和知识库缺口记录。
- “我的”页保留宠物档案、宠物知识库入口和装扮区，只增加“用户激励”入口；未再把装扮拆成同级入口集合。
- 用户激励页已独立成页，展示今日积分、本周积分、连续天数、任务完成数、排名和奖励进度，并提供“每日任务”“排行榜”“奖励/可解锁服饰”三个可点击入口。
- 每日任务详情页展示任务具体内容、完成/未完成状态、任务原因、时间窗口和积分；点击未完成任务后，今日积分、完成数、连续天数、周积分和排名会联动更新。
- 排行榜详情页展示完整排行，排行条目可点击查看明细；当前宠物分数来自本地任务完成状态。
- 奖励/可解锁服饰页展示巡逻奖章、生日丝巾、连续照护徽章的来源、条件和进度；装扮页中“生日丝巾”“巡逻奖章”等奖励项会显示未解锁/已解锁状态和解锁条件。
- 修复了用户激励子页返回按钮被顶部导航层拦截的问题，并调整“我的”页滚动时 sticky 顶部遮罩，避免标题与装扮标签叠读。
- 社区页恢复为照护经验流，不再承载用户个人激励主入口。
- 知识库已更新：用户激励从“我的”页进入独立子流程；任务积分、排行榜和奖励解锁从泛社区 P2 拆为当前 Demo 用户激励闭环；装扮页不再承担奖励来源解释。
- 验证：`npm run typecheck` 通过；Playwright 按“我的 -> 用户激励 -> 每日任务 -> 排行榜 -> 奖励/可解锁服饰 -> 装扮未解锁反馈”完成端到端验证，截图保存在 `/tmp/e2e-verify/ai-pet-user-incentive-v2/`。当前 5180 页面新增 console warning/error 为 0，非静态网络请求均为 200。
