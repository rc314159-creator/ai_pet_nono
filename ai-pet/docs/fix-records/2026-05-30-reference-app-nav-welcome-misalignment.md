# 2026-05-30 参考 App 底部导航与初始页未对齐问题记录

## 事实时间线

- 用户提供参考文件 `docs/参考/index.html`，要求在该基础上让下面几个窗口和初始页面保持一致，同时做自己的优化。
- 视觉迭代实现时，只提取了参考稿的暖色背景、圆形按钮、软卡片和手机应用视觉语言。
- 实际交付仍保留四个底部入口：对话、状态、换装、任务。
- 实际交付默认直接进入对话页，没有实现参考稿中的欢迎初始页和“开始陪伴”按钮。
- 用户指出参考稿底部应为五个入口：市集、社区、对话、状态、我的；初始页应为“毛球伙伴”介绍页，上面有“开始陪伴”按钮。

## 证据

- 参考稿底部导航为：市集、社区、对话、状态、我的。
- 参考稿默认页面为欢迎/介绍页，包含品牌名“毛球伙伴”和“开始陪伴”按钮。
- 当前应用窗口底部导航为：对话、状态、换装、任务。
- 当前应用窗口默认进入对话页。

## 根因

- 将“参考稿”理解成视觉风格参考，而没有把参考稿的信息架构也纳入对齐目标。
- 对产品规格中 3-4 个主入口的旧口径执行过重，未及时按当前用户指定的参考稿五入口调整。
- 验证时只检查了四个既有页签的视觉一致性，没有把参考稿初始页和底部导航数量作为验收项。

## 修复计划

1. 应用窗口启动后先显示欢迎初始页，包含“毛球伙伴”和“开始陪伴”按钮。
2. 底部导航改为五个入口：市集、社区、对话、状态、我的，顺序与参考稿一致。
3. “开始陪伴”进入对话页；底部对话按钮也能进入对话页。
4. “我的”承载当前换装/个人装扮页；任务能力暂时移入状态/市集/后续入口，不再作为底部一级入口。
5. 补充 Playwright 截图验证 welcome、market、community、chat、status、my 六个页面。

## 修复结果

- 已新增欢迎初始页“毛球伙伴”和“开始陪伴”按钮。
- 已将底部导航改为：市集、社区、对话、状态、我的。
- 已新增市集页和社区页 mock 展示。
- 已将原换装页调整为“我的”入口。
- 已保留对话页 Agent 交互和宠物动作指令逻辑。
- 已通过 `npm run typecheck`、`npm run build` 和 Playwright 截图验证。
