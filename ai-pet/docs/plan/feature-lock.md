## 2026-05-30 开发侧明确约束

- 当前目标不是规划多个版本，而是完成明天汇报使用的一版项目展示 Demo；讨论时不要再问“第一版/第二版数据来源”这类版本问题。
- 团队当前角色是开发，不是展陈或 PPT 包装；所有讨论优先服务于产品定义、功能闭环和工程实现。
- 产品主闭环中 AI 电子宠物陪伴和真实宠物数字分身共存；电子宠物可以是虚拟宠物，也可以是真实宠物在系统中的分身。
- 用户优先级是先服务已有真实宠物的人群，同时兼顾没有真实宠物但需要电子宠物陪伴的人群。
- 桌宠必须是核心入口，不只是表现层；点击桌宠后必须能弹出应用窗口/功能面板。
- 项目没有 HTML 展示页，不做静态网页看板或汇报页。
- 当前优先系统级桌宠 + 桌宠弹出的应用窗口；其他端口后续再讨论。
- 换装先作为 MVP 陪伴玩法落地，电商和商品推荐作为后续商业化入口预留。
- 安全边界当前不作为产品讨论焦点。
- AI 相关能力不以 API Key 或算力作为限制条件；用户已明确有可用 API Key，也有 8 张 4090 可用。
- AI 相关功能必须优先调用成熟 agent、成熟模型服务或成熟工具协议，不从零手写 agent 框架；当前方向是 OpenCode SDK / opencode runtime。
- 开发讨论应聚焦产品到底解决什么问题、哪些场景必须跑通、如何把成熟 AI 能力接到产品闭环里。

## 必须做

- Demo 必须包含系统级桌面宠物窗口；只有独立应用窗口、浏览器里的虚拟舞台或静态展示页不算完整 Demo。
- 点击桌宠后必须弹出应用窗口/功能面板，默认进入陪伴对话主页。
- 桌面宠物必须能被 AI Pet 数据驱动，至少支持显示/唤醒、气泡发言、状态反应。
- 桌面宠物必须承担核心入口职责，包括点击展开、轻交互、任务提醒、异常提醒和 Agent 输出。
- 使用 mock 宠物数据，不等待真实硬件。
- mock 数据要仿照宠物项圈/手环设备输出，而不是随便编几个字段。
- mock 数据要长且全面，足够支撑最终 demo 展示。
- 真实宠物数据驱动虚拟宠物状态；设备绑定可以开关。
- 虚拟宠物形象取决于真实宠物形象。
- 不要求展示人形角色；桌宠主形象以猫狗宠物为主。
- 用户每天可以和虚拟宠物娱乐互动。
- 支持陪伴对话和 AI 问答，回答必须结合宠物档案、健康/活动数据、异常、库存和任务。
- 一个宠物对应一个连续对话上下文，并维护用户记忆和宠物记忆。
- 支持宠物知识问答，例如饮食、洗澡、受伤、活动异常。
- 支持数据与异常视图，展示摄食、运动、睡眠、定位、特殊行为和护理记录。
- 支持异常触发：进食量明显变化、长时间未进食、运动量明显下降、睡眠异常、特殊行为异常、位置异常。
- 支持异常报告：每条异常包含 AI 分析和处理建议，通知的是异常，不是孤立建议。
- 每天给出喂养、遛狗、护理建议。
- 支持换装/互动，至少能应用一个内置装扮模板并同步到桌宠。
- 结合宠物电商做商业化推荐作为后续入口预留，推荐必须由库存/健康/任务触发。
- 预留社区比赛/挑战展示，但不阻塞当前 MVP。
- 开发过程中持续同步知识库；每个新对话都先回顾 `docs/INDEX.md`、产品 spec、技术架构和模块索引。
- 使用 LLM 时直接使用 llmmelon 中转站，不使用其它默认供应商。
- AI/agent 能力直接接成熟 agent 或模型服务，不从零实现。

## 不允许偏离

- 不从零开发桌宠核心运行时，优先基于 OpenPets 这类现有项目。
- 不从零写 agent 框架；不把大量自研 agent glue code 作为主线。
- 安全边界当前不作为产品讨论焦点；实现层可保留必要底线，但不要把它作为待用户确认的问题。
- 不依赖真实硬件 API 才能演示。

## Demo 要展示的场景

1. 打开 demo 后先看到系统桌面上的 OpenPets 桌宠窗口。
2. 桌宠能显示 AI Pet 生成的 Mochi 今日提醒，并可被点击。
3. 点击桌宠后弹出应用窗口/功能面板，默认进入陪伴对话主页。
4. 主页显示当前宠物形象，并能进行连续陪伴对话。
5. 看到仿硬件设备输出的数据摘要：摄食、运动、睡眠、定位、心率、呼吸、体温、抓挠/舔毛/吠叫等。
6. mock 数据触发异常后，桌宠弹出异常提示。
7. 用户点击异常提示进入异常报告，看到 AI 分析和处理建议。
8. 今日任务自动生成，并能解释为什么要做。
9. 用户点击喂食、玩耍、护理后，虚拟宠物状态变化，桌宠可被唤醒反馈。
10. 用户进入换装/互动视图，应用一个内置装扮，装扮结果同步到对话主页和桌宠。
11. AI 问答能回答“今天要不要洗澡”“伤口怎么办”“粮够不够”“为什么出现这个异常”。
12. 库存不足或任务需要时，可以出现推荐入口；社区挑战仅保留预览，不作为当前核心开发闭环。
