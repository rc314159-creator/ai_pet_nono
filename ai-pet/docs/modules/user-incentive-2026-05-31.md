# AI Pet 用户激励、每日任务与奖励解锁模块

## 模块定位

用户激励不是社区功能的附属品，也不是“我的”页里的大块静态内容。它是照护任务模块的反馈层，用来把真实照护行为变成可见的正反馈：

1. 完成每日任务获得积分。
2. 积分影响连续天数、周积分和排行榜。
3. 达成条件解锁奖励或服饰。
4. 装扮页只展示和使用奖励解锁状态，不负责解释奖励体系。

完整开放社区、UGC、真实比赛运营可以后置；但每日任务、积分、排行榜和奖励解锁是当前 Demo 的 P0 用户激励闭环。

## 信息架构

应用窗口底部导航仍只有 5 个主入口：市集、社区、对话、状态、我的。用户激励不是新的底部一级入口。

```text
我的
├─ 宠物档案 / 账户信息 / 宠物知识库入口
├─ 用户激励入口
│  └─ 用户激励页
│     ├─ 每日任务详情页
│     ├─ 排行榜详情页
│     └─ 奖励 / 可解锁服饰页
└─ 我的装扮区
   ├─ 服装
   ├─ 毛发
   ├─ 妆容
   └─ 配饰
```

关键边界：

- “我的”页是个人、宠物档案、知识库和装扮的承载页，只放一个“用户激励”入口，不在首页堆完整任务列表、排行榜和奖励清单。
- “用户激励页”是独立页面，展示积分、连续天数、奖励进度和进入任务/排行/奖励详情的入口。
- “每日任务详情页”展示具体任务、完成/未完成状态、任务原因、时间窗口和积分，任务可点击完成。
- “排行榜详情页”展示完整排名，排名条目可点击查看明细，并高亮当前宠物。
- “奖励/可解锁服饰页”展示奖励来源、解锁条件和当前进度；任何装扮页中标注“奖励获得”的服饰或配饰，都必须在这里有对应来源。
- “我的装扮区”不是因为用户激励而拆出的同级入口；它保持“我的”页内既有功能，消费奖励解锁状态。

## 页面职责

### 我的页

必须保留：

- 当前宠物头像、名字、品种、年龄等资料。
- 宠物知识库入口。
- 用户激励入口。
- 装扮分类与保存能力。

不得出现：

- 完整每日任务列表。
- 完整排行榜。
- 完整奖励清单。
- 把“用户激励”和“桌宠装扮”做成两个并列大入口后，导致“我的”页只剩入口集合。

### 用户激励页

展示：

- 今日积分 / 今日可得积分。
- 本周积分。
- 连续照护天数。
- 今日任务完成数。
- 当前排行榜名次。
- 奖励进度摘要。

可点击入口：

- 每日任务。
- 排行榜。
- 奖励 / 可解锁服饰。

### 每日任务详情页

每个任务至少展示：

- 任务标题。
- 完成状态：已完成 / 未完成。
- 任务原因：为什么今天推荐做这件事。
- 时间窗口。
- 任务优先级。
- 可获得积分。

交互要求：

- 未完成任务可点击完成。
- 完成后立即更新今日积分、完成数、连续天数、周积分和排行榜中的当前宠物分数。
- 已完成任务必须有明确状态，不能只靠颜色暗示。

### 排行榜详情页

每个排行条目至少展示：

- 排名。
- 宠物名。
- 家庭/用户标签。
- 积分。
- 本周完成任务数。
- 连续天数或主题徽章。

交互要求：

- 排行条目可点击。
- 点击后展示该条目的明细。
- 当前宠物必须高亮，且分数来自本地任务完成状态，不能是静态 mock 数字。

### 奖励 / 可解锁服饰页

每个奖励至少展示：

- 奖励名称。
- 奖励类型：服饰、配饰、徽章或道具。
- 解锁条件：连续天数、累计积分、完成任务数、排名或特定任务。
- 当前进度。
- 解锁状态：已解锁 / 进行中 / 未开始。

装扮页约束：

- 如果服饰或配饰文案写“奖励获得”“连续照护解锁”“任务奖励”等，用户激励页必须能看到对应奖励项。
- 未解锁的奖励服饰可以在装扮页展示为预览，但应明确“未解锁”和解锁条件。
- 当前真实桌宠换装只承诺配饰同步；服装、毛发、妆容仍为应用窗口预览或后续方案。

## 数据模型最低要求

当前 Demo 可先用本地 state/mock 数据，但结构必须能迁移到 Domain Service：

```ts
type UserIncentiveSummary = {
```

## 当前 Demo 验收标准

必须通过以下路径：

1. 进入“我的”页，能看到“用户激励”入口，同时仍能看到原本宠物资料和装扮功能。
2. 点击“用户激励”，进入独立用户激励页。
3. 点击“每日任务”，进入每日任务详情页；能看到任务具体内容、完成/未完成状态和积分；点击未完成任务后，积分和完成数变化。
4. 返回用户激励页，点击“排行榜”，进入排行榜详情页；每个排名条目可点击，当前宠物分数随任务完成变化。
5. 返回用户激励页，点击“奖励/可解锁服饰”，能看到装扮页里标注奖励获得的服饰或配饰对应解锁来源和进度。
6. 回到“我的”页，装扮功能仍在“我的”页中，不被改造成独立同级入口集合。
