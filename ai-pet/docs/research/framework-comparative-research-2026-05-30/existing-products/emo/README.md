# EMO

## 产品定位

EMO 是 LivingAI 的桌面 AI robot pet，强调 personality、ideas、自主探索、1000+ faces and movements，以及回答问题、拍照、音乐、舞蹈、闹钟和智能家居帮助。

## 可验证能力

官方页面呈现：

- 多传感器和技术。
- self-explore the world。
- 1000+ faces and movements。
- music、dance、online games。
- wakes you up、turns on the light、takes pictures、answers questions。
- 能追踪声音，识别人和物体，桌面导航避免掉落。
- personality evolves based on surroundings and interactions。

## 对 AI Pet 的启发

EMO 是“桌面存在感”的好样本。AI Pet 即使先用软件桌宠，也要让宠物看起来不是静态 widget：

- 有 idle 行为。
- 有情绪表情。
- 有被打断/被关注的反馈。
- 会主动提醒，而不是只等用户问。

## 不适合照搬的地方

EMO 是实体机器人，硬件能力不可复制；其“回答问题”偏通用助手，容易偏离真实宠物照护。AI Pet 需要保持宠物和照护语境。

## MVP 采用方式

用 OpenPets 表现 EMO 式桌面存在：

- idle / alert / happy / tired / warning。
- 任务完成时庆祝。
- 异常数据时主动气泡。
- 用户长时间未互动时温和提醒。
