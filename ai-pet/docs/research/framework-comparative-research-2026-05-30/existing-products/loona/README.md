# Loona

## 产品定位

Loona 是 KEYi 的 AI-powered robotic pet / petbot，强调家庭互动、移动机器人、语音命令、视觉能力和 GPT 交互。官网页面在本次抓取中被验证页拦截，因此事实主要参考可访问的公开官方/新闻稿信息和既有调研。

## 可验证能力

公开信息显示其定位包括：

- AI-powered robotic pet。
- 自然对话和语音命令。
- 视觉识别/交互。
- 家庭 companion。
- 移动机器人表达。

用户侧公开反馈里也能看到常见风险：语音识别、App 稳定性、售后和期望管理容易影响体验。

## 对 AI Pet 的启发

Loona 说明“具身移动”很吸引人，但它也把复杂度拉到最高：

- 移动避障。
- 语音唤醒。
- 视觉识别。
- 机械可靠性。
- 售后和供应链。

对 AI Pet 来说，Loona 适合作为远期形态想象，不适合作为 MVP 复用路径。

## 不适合照搬的地方

硬件机器人风险远超当前项目目标。MVP 如果试图模拟 Loona，会把焦点从“真实宠物数据解释 + 桌宠表达”带到机器人控制和硬件问题。

## MVP 采用方式

只借鉴交互叙事：

- 宠物主动来找你。
- 听到名字有反应。
- 对状态变化有动作。
- 远程陪伴和家庭场景。

工程上仍用桌面/Web 表达模拟。
