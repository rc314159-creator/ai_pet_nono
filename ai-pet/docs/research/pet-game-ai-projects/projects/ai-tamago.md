# AI-tamago

- 类型：开源 LLM 虚拟宠物。
- 来源：[GitHub ykhli/AI-tamago](https://github.com/ykhli/AI-tamago)
- 当前状态：2026-05-30 本地 GitHub 查询：约 519 stars，JavaScript，近期仍有更新。
- AI 结合：本地就绪的 LLM 生成和驱动虚拟宠物，强调想法和情感。

## 能力方向

AI-tamago 是“LLM-native 虚拟宠物”的直接参考：宠物不只是状态条，也有语言、想法和情绪表达。

## 可复用点

- 本地 Web 技术栈易拆解。
- 情绪/想法可以作为桌宠气泡的内容来源。
- 适合参考 LLM prompt、状态到语言的映射。

## 风险与限制

- 真实宠物档案、健康数据、库存和商品推荐不是其主线。
- LLM 输出如果没有事实服务约束，容易变成空泛陪聊。

## 对 AI Pet 的启发

可参考“LLM 表达层”，但状态事实必须由 Domain Service 计算，LLM 只解释和个性化表达。
