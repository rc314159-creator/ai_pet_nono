# tama96

- 类型：开源虚拟宠物 / desktop / terminal / AI agent。
- 来源：[tama96 官网](https://www.tama96.com/)、[GitHub siegerts/tama96](https://github.com/siegerts/tama96)
- 当前状态：2026-05-30 本地 GitHub 查询：约 19 stars，Rust/Tauri/TUI/MCP 标签，近期更新。
- AI 结合：强调可用于桌面、终端或 AI agent，并带 MCP 方向。

## 能力方向

tama96 把复古 Tamagotchi 和现代 agent/MCP 接口连接起来，是和 OpenPets 同类但更轻量的参考。

## 可复用点

- MCP 方向与本项目架构一致。
- Tauri/Rust/TUI 说明桌宠不必只走 Electron。
- “照护选择塑造宠物”适合做长期记忆。

## 风险与限制

- 项目规模小，生态和资产能力弱。
- 不直接处理真实宠物健康数据。

## 对 AI Pet 的启发

继续以 OpenPets 为桌宠主底座，同时参考 tama96 的轻量 MCP 接口和复古照护模型。
