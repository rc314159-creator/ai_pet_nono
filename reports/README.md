# Reports Index

本目录保存 AI Pet 的生成型验证材料、调研 HTML、截图和运行证据。这里不是产品规格真相源；产品结论必须同步回 `ai-pet/docs/`。

## 当前报告目录

- `application-window-ui-2026-05-30/`：手机比例应用窗口截图，对话、状态、换装、任务四个入口。
  - `application-window-ui-2026-05-30/redesign-v2/`：基于 `docs/参考/index.html` 视觉语言统一后的应用窗口截图。
  - `application-window-ui-2026-05-30/reference-aligned-v3/`：对齐参考 App 初始欢迎页和五入口底部导航后的截图。
  - `application-window-ui-2026-05-30/interactive-mock-v4/`：应用窗口可点击 mock 验证截图，覆盖市集分类/商品详情、社区搜索/帖子详情、状态日期/健康报告和我的页装扮保存。
- `legacy-root-screenshots/`：从根目录清理归档的早期临时截图。
- `desktop-photo-pet-*`：桌面端宠物形象线的截图、GIF 和动作验证产物。
- `ai-pet-framework-summary/`、`pet-sandbox-overnight/`：早期历史验证材料，不代表当前产品形态。
- `*-research*`：调研报告及截图。

## 归档规则

- 根目录不直接放 `.png`、`.gif`、`.log` 等临时产物。
- 新截图按任务建立子目录，例如 `reports/application-window-ui-YYYY-MM-DD/`。
- 需要被项目长期引用的报告，在 `ai-pet/docs/INDEX.md` 或对应实现记录中链接。
