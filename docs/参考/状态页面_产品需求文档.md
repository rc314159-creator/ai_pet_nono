# 状态页面 - 产品需求文档

## 文档信息
- 页面名称：状态监测页（底部导航"状态"Tab）
- 文档版本：V1.0
- 文档日期：2026年5月31日
- 页面尺寸：430×932（手机竖屏比例）
- 主色调：奶油白 #FFF8F3 + 暖橙渐变 #FF9A76/#FFB4A2

---

## 一、页面整体结构

状态页面是产品的**宠物健康数据监测核心页面**，用户可在此查看宠物实时状态、历史健康数据、异常事件记录及周期性健康评估报告。

### 页面层级

状态页面由**一个主页面**和**两个侧滑面板**组成：

| 层级 | 名称 | 触发方式 | 方向 |
|------|------|---------|------|
| 主页面 | 状态监测主页 | 底部Tab"状态" | - |
| 侧滑面板A | 异常历史 | 点击"异常历史"按钮 | 从左侧滑出 |
| 侧滑面板B | 健康评估报告 | 点击"健康评估"按钮 | 从右侧滑出 |

---

## 二、主页面布局与功能

### 2.1 顶部导航栏

| 元素 | 位置 | 说明 |
|------|------|------|
| 返回按钮 | 左侧 | 圆形白色按钮，内含左箭头SVG图标 |
| 标题"状态监测" | 居中 | 17px加粗，下方小字显示"05-30 数据已同步" |
| 设置按钮 | 右侧 | 圆形白色按钮，内含齿轮SVG图标 |

### 2.2 快捷入口按钮

位于顶部导航下方，两个胶囊形按钮并排展示：

| 按钮 | 样式 | 功能 |
|------|------|------|
| 异常历史 | 橙色背景（#FFF3ED），橙色文字+图标 | 点击后从左侧滑出异常历史面板 |
| 健康评估 | 蓝色背景（#EBF5FB），蓝色文字+图标 | 点击后从右侧滑出健康评估面板 |

### 2.3 宠物状态卡片

白色圆角大卡片，左侧为宠物图片，右侧为状态信息。

**左侧 - 宠物图片区域：**
- 130×130px圆角矩形，展示宠物真实照片（通过智能项圈采集或用户上传）
- 右上角有ZZZ浮动动画（当宠物处于睡眠状态时显示）
- ZZZ动画：3个Z字母依次从右下向右上浮动，循环播放，蓝色（#7EC8E3）

**右侧 - 状态信息区域（从上到下）：**
1. **宠物位置**：定位图标（橙色SVG）+ 位置名称文字（如"旺财大宅"），12px灰色字
2. **当前状态**：蓝色圆点（脉冲呼吸动画）+ 状态文字（如"睡眠中"），22px加粗
3. **状态描述**：13px灰色文字（如"旺财美梦生成中 ZZZ"）

**状态类型与对应展示：**

| 状态 | 状态文字 | 描述示例 | 圆点颜色 |
|------|---------|---------|---------|
| 睡眠 | 睡眠中 | 旺财美梦生成中 ZZZ | 蓝色 #7EC8E3 |
| 活动 | 活动中 | 旺财正在客厅溜达 | 绿色 #7ED3A8 |
| 进食 | 进食中 | 旺财正在享用晚餐 | 粉色 #F4A9A8 |
| 异常 | 异常 | 旺财进食量偏低，需关注 | 橙色 #FF8A65 |

### 2.4 日历选择器

横向展示最近7天日期，居中排列。

| 元素 | 说明 |
|------|------|
| 布局 | 水平居中，7个日期项等间距排列 |
| 日期项 | 上方星期标签（11px灰色），下方日期数字（16px加粗） |
| 选中状态 | 白色背景 + 阴影，星期标签变为橙色 |
| 交互 | 点击切换日期，页面数据同步更新为对应日期的数据 |

### 2.5 数据模块卡片

三个数据模块纵向排列，每个模块为白色圆角卡片，左侧有彩色竖条标识。

#### 模块通用结构

```
┌─────────────────────────────┐
│ ▎ [图标] 模块名称            │  ← 左侧彩色竖条 + 图标 + 标题
│ ▎       总时长 XX时XX分      │  ← 22px加粗总时长
│ ▎                     [...]  │  ← 更多按钮（三点图标）
│─────────────────────────────│
│  ● 深度睡眠    ● 浅度睡眠    │  ← 子分类数据项
│  2时24分      1时14分       │     14px数值 + 10px单位
└─────────────────────────────┘
```

#### 三大模块详情

**（1）睡眠模块**
- 色条颜色：蓝色 #7EC8E3
- 图标：月亮SVG
- 总时长展示：XX时XX分
- 子分类：深度睡眠、浅度睡眠
- 子分类圆点：蓝色，不同透明度区分

**（2）活动模块**
- 色条颜色：绿色 #7ED3A8
- 图标：时钟SVG
- 总时长展示：XX分XX秒
- 子分类：行走、奔跑、打滚、跳跃
- 子分类圆点：绿色，不同透明度区分

**（3）休闲模块**
- 色条颜色：粉色 #F4A9A8
- 图标：层叠SVG
- 总时长展示：XX时XX分
- 子分类：嗅闻、摄食、发呆、舔舐、磨爪
- 子分类圆点：粉色，不同透明度区分
- 注意：5个子分类需在页面宽度内完整展示，不换行

## 三、异常历史面板（左侧滑出）

### 3.1 面板基础信息

| 属性 | 说明 |
|------|------|
| 滑出方向 | 从左侧滑入 |
| 面板宽度 | 设备宽度的85% |
| 背景遮罩 | 半透明黑色遮罩（rgba(0,0,0,0.3)），点击遮罩关闭面板 |
| 动画 | 0.4s cubic-bezier(0.4, 0, 0.2, 1) |
| 关闭方式 | 点击右上角关闭按钮 / 点击遮罩层 |

### 3.2 面板头部

| 元素 | 说明 |
|------|------|
| 标题"异常历史" | 18px加粗，左对齐 |
| 关闭按钮 | 圆形白色按钮，X形SVG图标 |

### 3.3 异常事件列表

面板body区域可上下滚动，展示所有历史异常事件。

#### 异常事件卡片结构

```
┌─────────────────────────────┐
│ [WATCH/RESOLVED]             │  ← 状态标签
│ 异常名称            时间     │  ← 标题行
│ 异常摘要文字                 │  ← 简要描述
│                         [▼]  │  ← 展开/折叠箭头
├─────────────────────────────┤  ← 点击后展开
│ 具体数据                     │
│  数据项1      数值           │
│  数据项2      数值           │
│                             │
│ ┌─ AI智能诊断 ─────────────┐│
│ │ AI分析文字内容            ││
│ └───────────────────────────┘│
└─────────────────────────────┘
```

#### 状态标签

| 标签 | 样式 | 含义 |
|------|------|------|
| WATCH | 橙色背景，橙色文字 | 待观察的异常事件 |
| RESOLVED | 绿色背景，绿色文字 | 已恢复/已解决的异常事件 |

#### 展开详情内容

展开后包含两个模块：

**（1）具体数据模块**
- 标题："具体数据"，带时钟图标
- 数据行：左标签 + 右数值，灰色背景圆角行
- 异常数值用橙色字体标注

**（2）AI智能诊断模块**
- 蓝色渐变背景卡片
- 标题行：蓝色"AI"标签 + "智能诊断分析"文字
- 正文：12px灰色文字，1.6倍行高
- 内容包含：可能原因分析（编号列表）+ 建议措施

#### 交互规则

- 点击异常卡片可展开/折叠详情
- 同一时间只允许一个卡片展开（手风琴模式）
- 展开动画：max-height过渡，0.4s

### 3.4 异常事件数据字段

每条异常事件需包含以下字段：

| 字段 | 类型 | 说明 |
|------|------|------|
| 状态 | 枚举 | WATCH / RESOLVED |
| 异常名称 | 文本 | 如"进食下降+抓挠升高" |
| 时间 | 文本 | 如"05-29 14:32" |
| 摘要 | 文本 | 一句话描述异常情况 |
| 具体数据 | 列表 | 数据项名称 + 数值（含基线对比） |
| AI诊断 | 文本 | 多段分析内容，包含原因和建议 |

## 四、健康评估报告面板（右侧滑出）

### 4.1 面板基础信息

| 属性 | 说明 |
|------|------|
| 滑出方向 | 从右侧滑入 |
| 面板宽度 | 设备宽度的85% |
| 背景遮罩 | 与异常历史共享同一遮罩层 |
| 动画 | 0.4s cubic-bezier(0.4, 0, 0.2, 1) |
| 关闭方式 | 点击右上角关闭按钮 / 点击遮罩层 |

### 4.2 面板头部（两行）

**第一行：**
| 元素 | 位置 | 说明 |
|------|------|------|
| 标题"健康评估报告" | 左侧 | 17px加粗，左对齐 |
| 关闭按钮 | 右侧 | 圆形白色按钮，X形SVG图标 |

**第二行：周选择器**
| 元素 | 位置 | 说明 |
|------|------|------|
| 左箭头按钮 | 左侧 | 圆形白色按钮，左箭头SVG，点击切换到上一周 |
| 周标签 | 居中 | 显示"本周（5月24日 - 5月30日）"，14px |
| 右箭头按钮 | 右侧 | 圆形白色按钮，右箭头SVG，点击切换到下一周 |

**周切换交互：**
- 点击左箭头：查看更早一周的报告
- 点击右箭头：查看更近一周的报告
- 切换时内容区域有左右滑动动画（0.3s）
- 评分环、进度条、柱状图在切换后重新播放入场动画
- 到达最早/最新一周时，对应方向按钮仍可点击但无效果（或可禁用样式）

### 4.3 报告内容结构（从上到下）

#### （1）综合健康评分卡

- 橙色渐变背景（#FF9A76 → #FFB4A2 → #FFCCBC）
- 圆角大卡片，居中展示
- **评分环**：SVG圆环进度条，白色描边，动画从0填充到对应分数
- **评分数字**：环中心显示分数（如78），数字递增动画
- **标签**："综合健康评分"
- **日期**：报告周期（如"2026年5月24日 - 5月30日"）

#### （2）健康维度分析

白色卡片，包含4个维度的评分条和分析文字。

每个维度的结构：
```
┌─────────────────────────────┐
│ 睡眠  ████████░░  85  [持平] │  ← 标签 + 进度条 + 分数 + 趋势
├─────────────────────────────┤
│ 深度睡眠占比稳定在63%...    │  ← 分析文字
└─────────────────────────────┘
```

**4个维度：**

| 维度 | 色条颜色 | 说明 |
|------|---------|------|
| 睡眠 | 蓝色 | 深度睡眠占比、睡眠节律、夜间醒来次数 |
| 活动 | 绿色 | 活动量、运动模式、精神状态 |
| 饮食 | 粉色 | 进食量、进食速度、饮水情况 |
| 行为 | 蓝色 | 舔舐频率、嗅闻探索、整体行为模式 |

**趋势指示器：**

| 趋势 | 样式 | 含义 |
|------|------|------|
| 上升 | 绿色背景，上箭头 | 较上周改善 |
| 下降 | 橙色背景，下箭头 | 较上周恶化 |
| 持平 | 灰色背景，横线 | 与上周基本一致 |

**分析文字样式：**
- 正常分析：浅灰色背景（rgba(0,0,0,0.02)），深色文字
- 预警分析：橙色背景（#FFF3ED），橙色文字，左侧橙色竖条

#### （3）本周活动趋势

白色卡片，包含柱状图可视化 + 趋势分析文字。

**柱状图：**
- 7根柱子，对应周一至周日
- 绿色柱子表示正常，橙色柱子表示低于基线
- 柱子高度代表当日活动量占比
- 入场动画：柱子从0高度逐个生长（间隔100ms）
- 柱子下方显示星期标签

**趋势分析文字：**
- 位于柱状图下方
- 灰色背景圆角区域
- 描述本周活动量变化趋势

#### （4）本周异常事件

白色卡片，列出本周触发的所有异常事件。

- 每行：异常描述 + 状态标签（待观察/已恢复）
- 灰色背景行，左标签 + 右标签
- 下方有汇总分析文字

#### （5）本周健康建议

白色卡片，AI综合建议。

- 蓝色渐变背景区域
- 标题："AI 综合建议"，带灯泡图标
- 建议列表：每条建议前有蓝色圆点
- 建议内容基于本周数据综合生成

### 4.4 周数据结构

每周报告数据需包含以下字段：

| 字段 | 类型 | 说明 |
|------|------|------|
| title | 文本 | 周标签显示文本（如"本周（5月24日 - 5月30日）"） |
| date | 文本 | 完整日期（如"2026年5月24日 - 5月30日"） |
| score | 数字 | 综合健康评分（0-100） |
| dims | 数组 | 4个维度数据，每个含name/score/trend/color/analysis/warn |
| chartHeights | 数组 | 7天活动量柱状图高度百分比 |
| chartColors | 数组 | 7天柱状图颜色（green/orange） |
| chartAnalysis | 文本 | 活动趋势分析文字 |
| alerts | 数组 | 异常事件列表，每个含text/status/label |
| alertAnalysis | 文本 | 异常事件汇总分析 |
| advice | 数组 | 健康建议文字列表 |

## 五、交互逻辑与数据流

### 5.1 数据来源

| 数据类型 | 来源 | 更新频率 |
|---------|------|---------|
| 宠物状态 | 智能项圈实时采集 | 实时（秒级） |
| 宠物位置 | 智能项圈GPS | 每30秒 |
| 健康数据（睡眠/活动/休闲） | 智能项圈传感器采集 | 实时聚合 |
| 异常事件 | 后端规则引擎自动判定 | 事件触发时 |
| AI诊断 | 后端AI模型生成 | 异常触发时 |
| 健康评估报告 | 后端定期生成 | 每周自动生成 |

### 5.2 页面跳转逻辑

```
状态主页
  ├── 点击"异常历史" → 左侧滑出异常历史面板
  │     └── 点击遮罩/关闭 → 收回面板
  └── 点击"健康评估" → 右侧滑出健康评估面板
        ├── 点击左箭头 → 切换到上一周报告
        ├── 点击右箭头 → 切换到下一周报告
        └── 点击遮罩/关闭 → 收回面板
```

### 5.3 日历切换逻辑

- 用户点击日历中的某一天
- 该天高亮显示（白色背景+阴影）
- 页面中所有数据模块更新为所选日期的数据
- 宠物状态卡片同步更新为该日最后记录的状态

### 5.4 异常监测规则

| 异常类型 | 判定规则 | 严重程度 |
|---------|---------|---------|
| 进食异常 | 进食量较7日基线偏差超过20% | 中 |
| 未进食 | 超过设定时长未检测到进食行为 | 高 |
| 运动不足 | 运动量较7日基线减少超过30% | 中 |
| 长时间静止 | 持续静止时间超过设定阈值 | 高 |
| 行为异常 | 舔舐/抓挠频率超过7日基线2倍 | 中 |
| 饮水异常 | 饮水量较7日基线偏差超过20% | 中 |
| 进食速度异常 | 进食速度较7日基线偏差超过30% | 低 |

## 六、动效说明

| 动效名称 | 触发条件 | 动画描述 | 时长 |
|---------|---------|---------|------|
| ZZZ浮动 | 宠物处于睡眠状态 | 3个Z字母依次从右下向右上浮动并渐隐 | 2.5s循环 |
| 状态脉冲 | 状态卡片展示中 | 蓝色圆点呼吸式缩放 | 2s循环 |
| 面板滑出 | 点击异常历史/健康评估按钮 | 面板从侧边滑入 + 遮罩淡入 | 0.4s |
| 面板收回 | 点击关闭/遮罩 | 面板滑出 + 遮罩淡出 | 0.4s |
| 卡片展开 | 点击异常事件卡片 | max-height从0展开 | 0.4s |
| 评分环填充 | 健康评估面板打开/切换周 | SVG圆环从0填充到目标值 | 1.5s |
| 数字递增 | 健康评估面板打开/切换周 | 分数从0递增到目标值 | ~1s |
| 进度条填充 | 健康评估面板打开/切换周 | 进度条从0增长到目标宽度 | 1.2s |
| 柱状图生长 | 健康评估面板打开/切换周 | 柱子从0高度逐个生长 | 0.8s（间隔100ms） |
| 周切换滑动 | 点击左右箭头 | 内容区域左右滑动 + 淡出淡入 | 0.3s×2 |
